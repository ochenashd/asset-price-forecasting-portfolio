# Limitations and release gates

## Scientific evidence

All reported outcomes concern synthetic fixtures. The weekday UTC calendar is not a verified exchange calendar. Availability delays are declared rather than measured. The separately generated execution stream is a software-boundary fixture, not economically matched real data. No real-market predictive accuracy, profitable strategy or historical point-in-time validity is established.

The V1 keyed capture does not retain a complete per-prediction decision chronology. Feature availability survives in the temporal manifest, but historical signals are assembled after immutable bundle publication. Independent scientific consistency therefore remains incomplete. Saved-state replay can still reproduce 55 probabilities exactly; it does not fill missing chronology, authenticate a publisher or independently reproduce training.

## Execution and safety

Daily close marks miss intraday drawdowns. Annualization uses declared sampling assumptions. Short/margin engine tests do not turn the Long/Flat example into a live trading system. Transaction-cost parameters are explicit synthetic assumptions. No external execution, market-data provider or remote tracking service is part of the supported demo.

Only fresh owned native booster artifacts are loaded. Native parsing is not safe handling of hostile serialized models. Python API guards are cooperative controls, not complete filesystem/process isolation. Never supply private database credentials or historical stores.

## Packaging, platform and supply chain

A reviewed macOS arm64 CPython 3.11.5 Core environment was installed offline from 17 verified wheels including APF. That observed install does not establish a complete build/bootstrap lock or byte-identical repeated builds. Current macOS locks remain LOCK_PARTIAL. Linux remains LOCK_UNAVAILABLE: eight native Core wheels and greenlet/NCCL metadata are missing from the recorded evidence.

Native Linux validation is blocked by runtime availability; zero of eight mandatory native cases have executed. macOS deselection is explicit and is not Linux success. CI definitions are manual-only and fail closed on incomplete dependency evidence. Neither process interruption tests nor simulated errors establish power-loss durability.

VULNERABILITY_STATUS_UNVERIFIED remains. Full exact-version license/notice evidence for ANTLR runtime, Flask-CORS and XGBoost is incomplete. They are external runtime dependencies, not bundled dependency distributions in this source candidate; vendoring or distributing environments would require a different review scope.
